# Example vault

Three meetings of a made-up project ("Atlas launch") so you can see the roll-ups work before using your own notes.

1. Obsidian → **Open folder as vault** → choose this `example-vault` folder.
2. Settings → Community plugins → turn off Restricted mode → Browse → install and enable **Dataview**.
3. Open `Rollups/decision-log-rollup.md`: four decisions, newest first. Open `Rollups/action-items-rollup.md`: three open
   action items in three meetings (the done one is left out).
